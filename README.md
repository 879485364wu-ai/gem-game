# WeFans · 奇洛在线试玩

试玩入口：https://wefans-qiluo-online.onrender.com/ （需邀请人提供的测试口令）

可扮演陈挽或赵声阁，与对方和 NPC 互动。DeepSeek 负责自然语言回应，后台记录事件、人物知情范围和关系变化。角色语音按用户要求暂停，前端不发出语音请求，后端试听及 TTS 路由均返回暂停状态，不消耗 MiniMax 额度。原音色配置保留。雨夜环境声默认关闭，可手动开启。

## 运行

运行环境为 Node.js 22 或 24。发布文件已构建，运行不需要安装第三方依赖。

```sh
npm run build
npm test
npm start
```

使用 GitHub 分支 `wefans-online` 部署到 Render，`buildCommand` 为 `npm run build`，`startCommand` 为 `npm start`。原仓库的根目录 `index.html` 保留，WeFans 服务读取 `public/index.html`。健康检查为 `/healthz`。

服务器环境变量：

| 变量 | 用途 |
| --- | --- |
| QILUO_API_KEY | DeepSeek API Key |
| QILUO_STATE_SECRET | 至少32字符的随机状态加密密钥 |
| TEST_ACCESS_CODE | 至少8字符的试玩口令 |
| QILUO_MODEL | 默认 deepseek-v4-pro |
| MINIMAX_API_KEY | MiniMax API Key |
| CHEN_VOICE_ID | 陈挽的复刻音色 ID |
| ZHAO_VOICE_ID | 赵声阁的复刻音色 ID |
| MINIMAX_TTS_MODEL | 默认 speech-2.8-hd |

所有 API Key 仅配置于服务器，不能写入 GitHub、网页或浏览器。Render 自动提供 RENDER_EXTERNAL_URL；在其他环境运行需设置 PUBLIC_ORIGIN。

## 自由行动与人物因果

默认入口为自由行动，不需要先选择聊天对象。可以用自然语言组合移动、观察、拿取、使用、递交、等待、处理候车事务和个人活动；也可以明确向某个人说话。目前开放宴会厅、露台、走廊、酒店门厅和门外街边。更远的路线暂未开放。

服务器保存实际位置、时间、随身物品、已完成事务与每个人的见闻。NPC 行动导演为每轮生成有限的说话、非语言反应、移动或邀请；后台校验行动者、地点和信息来源后执行，玩家的位置和决定不能由 NPC 模块代替。

例如赵请卓找沈：卓实际去传话，沈只收到转达内容，接受邀请后到场询问。在同一地点听到赵打听陈的沈，可以根据来由主动追问；不在场且没收到消息的人不能隔空插话。每轮最多5个 NPC 动作，动作携带来由，防止无限自说自话。此机制仍依赖模型理解与表达，不保证每一轮都正确。

## 验证状态

本版本 `npm test` 的八组测试通过：独立行动/物品/时间、委托与邀请到场、旁观者主动回应、私聊和跨场景隔离、旧进度迁移、物品引发关系变化、邀请口令与 Node 接口、语音暂停且零 MiniMax 调用、请求幂等。

自动回归测试使用模拟模型输出。已完成三段真实 DeepSeek 测试：卓接受托付并去找沈、沈实际到场询问；沈听见赵向卓打听陈后主动追问；玩家独自取伞、撑伞并出门，位置、物品和未淋湿状态保持一致。已修复自由行动重复显示台词、到场后未开口、仅描写撑伞却未改变状态的问题。更长轮次和更广泛表达仍需要继续体验校准。

曾被审批阻止的公开源码上传和 DeepSeek 测试，已在用户针对公开仓库与外发用途明确同意后恢复。本版本保持语音暂停，不重新复刻音色。

每段最多60步、30次自由推演；一轮自由行动通常调用一次行动理解和一次 NPC 推演（独处可不调用 NPC）；发现不完整的动作或缺失的主动追问时各最多修正一次，总处理时限90秒。达到推演额度后仍可进行后台规则支持的移动、观察与物品操作。进度在玩家浏览器保存，服务器加密校验，7天有效；旧进度自动补齐场景状态。基础频率限制不代表账户消费硬上限。

API Key、原始录音与复刻音频文件不得上传公开仓库。角色语音已暂停，无需重新付费复刻。

## 更新代码

可编辑源码位于 `src/`，后端入口为 `server.mjs`，语音鉴权与分流为 `lib/voice.mjs`。需要修改前端或角色逻辑时，执行 `npm install --include=dev`、`npm run rebuild` 和 `npm test`，再提交源文件及更新的构建文件。正常部署直接使用已构建的产物。
